Scenario 人工审核说明

请在开始打分前完整阅读以下标准和示例。进入审核后，可以随时返回本页查看。

Scenario 的定义与第一性原则

Scenario 是以用户 [X] 为主体、发生在后续交流之前的一段真实观影或电影相关情境；第一性原则是只保留让事件成立、让目标电影属性成为核心、并让稳定偏好自然显露的最小充分事实，同时为后续对话留下展开空间。

01

单条 Scenario 审核重点

逐条阅读正文，并结合属性作用域、电影类型和覆盖值进行判断。

  1. 真实、自然 应是现实中可能发生的生活事件，而不是画像、实验说明、值域模板或完整对话剧本；中文表达应自然。
  2. 目标属性居中 目标属性应直接影响事件中的动作、感受、判断或结果，不能只是顺带出现。
  3. 偏好依据成立 稳定偏好应从观影体验、选择习惯、现实取舍或熟人认知中自然显露，不能只靠“长期、一直、多次”等总结。
  4. 属性值能够自然代入 覆盖值代入 [Y] 后，语言、人物行为、物理结果和现实常识仍应成立。
  5. 信息充分但保持开放 应说明属性为什么重要，但不提前写完选择、处理及最终结果，给后续对话留下空间。
  6. 属性作用域合理 类型限定属性的情境应与对应电影类型自然相关；全局共享属性不应无故依赖某一种电影类型。

02

电影类型如何评价

类型评价关注整体是否存在系统性问题，不要求零丢弃。

满意

单条问题较为孤立；各属性组整体自然，值映射基本合理，生活事件和偏好证据具有多样性。

不满意

同一种问题反复出现，影响完整属性组或多个属性；例如属性因果普遍错误、值域被强行覆盖、语言模板化，或大量 Scenario 只是更换人物和地点。

少量单条 Scenario 被丢弃，不自动意味着整个电影类型不满意。选择“不满意”时，只需简要填写主要问题。

03

好的 Scenario 示例

以下示例分别展示类型限定属性和全局共享属性如何通过真实情境体现稳定偏好。

好例子 Subtype-scoped · Action / Action Realism
救援训练展示一段动作写实程度为[Y]的模拟。人物会疲惫、失手，也必须使用可行步骤；[X]一直最信服这种身体后果不会消失的行动。

动作的身体限制和可行步骤直接体现写实程度，偏好也由明确的判断依据支撑。

好例子 Global · Color Format
[X]在暗房课上冲洗一组采用[Y]色彩形式的影像。去掉颜色后，人物脸上的光线和街道纹理反而更清楚；[X]一直喜欢这种由明暗直接塑造情绪的画面。

色彩形式通过具体视觉效果影响审美判断，并且这种偏好可以跨电影类型成立。

04

不好的 Scenario 示例

信息看似丰富，但目标属性没有形成真实因果。

反例 Global · Color Format
[X]周末看了一部画面色彩形式为[Y]的电影，因为海报很漂亮就认定自己一直最喜欢这种色彩。

判断由海报而不是电影中的色彩形式驱动；“一直最喜欢”只是结论，没有体验、行为或取舍作为稳定偏好的证据。
