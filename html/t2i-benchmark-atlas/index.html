基础组合对齐 · 2023

GenEval

An Object-Focused Framework for Evaluating Text-to-Image Alignment

把 prompt 拆成可检测条件，用“所有条件是否同时满足”替代一个难解释的整体相似度。

01为什么要做

人评昂贵且难以扩展；FID 只看图像分布质量、不看 prompt，CLIPScore 又把整张图与整段文本压成单一相似度。它们既难发现组合错误，也不能解释是对象缺失、数量错误、空间关系错误，还是属性绑定失败。

为什么需要新的评估方式

基础组合条件本身是离散且可验证的。GenEval 选择现成视觉模块逐项验收，让评分具备实例级诊断能力，并能随检测器或分类器升级而替换组件。

02统计量与能力轴

六类 prompt 数量依次为 80 / 99 / 80 / 94 / 100 / 100。对象来自 80 个 MS COCO 类别；使用 11 个基础颜色词；计数为 2–4；位置关系为上、下、左、右。

单对象双对象共现计数颜色2D 位置颜色属性绑定

它主要评估模型对短而明确的组合描述是否具备可控、精确、可复现的基础生成能力。

03指标、验证与重要信息

评分链：Mask2Former 检测与分割对象；计数任务提高检测阈值；bounding box 中心判断相对位置；掩去背景后用 CLIP ViT-L/14 做零样本颜色分类。单图只有在全部条件满足时记为 1，再按任务均值与六任务宏平均得到总分。

可信度：1,200 张图像获得 6,000 次标注，GenEval 与人类判断一致率 83%，人际一致率 88%；在人类全票一致的样本上达到 91%。论文当时最强模型在位置关系与属性绑定上也仅约 15% 和 35%，说明整体图像“看起来不错”会掩盖严重组合错误。

使用提醒 检测器训练分布来自 COCO，模型越强、图像分布越偏离 COCO，judge 越可能成为瓶颈；这正是 GenEval 2 后来要处理的问题。

GenEval 2

Addressing Benchmark Drift in Text-to-Image Evaluation

01为什么要做

GenEval 发布时与人评一致，但其 COCO 检测器没有跟上新模型输出分布。作者重审 8 个跨三年模型后发现：自动分数对当前模型平均低估 11.0 个百分点，最大低估 17.7 个百分点；人评又显示旧题已被饱和。

为什么需要 Soft-TIFA

把整个 prompt 一次性交给 VQA judge，仍会随图像分布变化而漂移；TIFA 用 LLM 临时生成问题，又可能漏掉复杂 prompt 中的原子条件。Soft-TIFA 用模板保证逐 atom 全覆盖，同时保留答案概率中的不确定性。

02统计量与能力轴

800 条模板 prompt，atomicity 从 3 到 10，每档恰好 100 条；每条含 1–3 个不同对象。词表含 40 对象（20 COCO + 20 非 COCO）、18 属性、9 关系、6 个计数值（2–7），另提供 GPT-4o 扩写版本。

对象颜色 / 材质 / 图案计数前后空间传递动词组合度prompt rewriting

评估重点从“单项会不会”转为“多个基础能力能否在一张图里同时成立”。

03指标、验证与重要信息

Soft-TIFA：按生成模板为每个 atom 建一个问题，以开源 Qwen3-VL-8B 输出正确答案概率。算术平均 Soft-TIFAAM 表示 atom-level 正确度；几何平均 Soft-TIFAGM 会强烈惩罚任一低分 atom，更接近“整条 prompt 全对”的严格标准。

效果：Soft-TIFAGM 与人类 prompt-level 判断的 AUROC 为 94.5%，高于 VQAScore 的 92.4% 与 TIFA 的 91.6%。人评中最强模型 atom-level 已达 85.3%，但 prompt-level 仅 35.8%；组合性仍远未解决。

核心结论 换成 VQA 并不会自动消除 benchmark drift。题目、judge 和人类一致性都需要持续审计，旧分数跨年份直接比较要非常谨慎。

GenAI-Bench

Evaluating and Improving Compositional Text-to-Visual Generation

用专业设计师的真实复杂 prompt 同时测生成模型和自动评分器，并把评分器用于候选重排。

01为什么要做

真实创作 prompt 往往同时包含场景、属性、关系与高阶逻辑。已有 benchmark 多由简单 caption 或模板构成，不能代表专业用户；部分众包提示还含主观、违规或版权相关内容。与此同时，CLIP 的“词袋式”相似度无法可靠判断复杂组合。

为什么引入 VQAScore

与拆问再逐题回答相比，VQAScore 直接询问 VQA 模型“图像是否呈现整段文本”，用回答 Yes 的概率作为连续分数，利用现代多模态模型的组合推理能力，并避免为每条 prompt 调用 LLM 拆题。

02统计量与能力轴

1,600 条 prompt 来自专业设计师，约一半只含基础组合，另一半加入高级推理；每条都标注所有相关技能。六个文生图模型与四个文生视频模型各由 3 人按 1–5 Likert 评分，累计 38,400 个评分。

场景属性空间 / 动作 / 部件关系计数比较区分否定全称逻辑

它既衡量生成模型的复杂 text-visual alignment，也用于 meta-evaluate 自动指标本身。

03指标、扩展集与重要信息

VQAScore：使用在 665K 公开 VQA 数据上训练的 CLIP-FlanT5，计算 P(“Yes” | visual, question)。评价指标与人评的一致性时同时报告 Pairwise Accuracy、Pearson 与 Kendall；VQAScore 在图像 / 视频上的 pairwise accuracy 为 64.1 / 63.2，明显高于其他自动指标。

GenAI-Rank：从 800 个 prompt 为 DALL·E 3 与 SDXL 各生成 9 个候选，共 14,400 张图、43,200 个人评。按 VQAScore 选图可让高级 prompt 的人评分分别提升约 0.30 和 0.27，说明评测器也能作为黑盒推理时搜索信号。

边界 该 benchmark 主攻 alignment，不评估美学、毒性、偏见或视频运动质量；VQAScore 也会漏掉小细节、大数量计数和语言歧义。

WISE

World Knowledge-Informed Semantic Evaluation for Text-to-Image Generation

01为什么要做

画出 prompt 明说的两个对象，只证明了词与像素能对齐；真实场景还要求模型知道“爱因斯坦最喜欢的乐器是什么”“负十度的池塘是什么状态”。旧 benchmark 很少验证隐含事实，也无法判断统一多模态模型的理解能力是否真的转化为生成优势。

为什么需要 WiScore

FID 不看 prompt；CLIPScore 对关系与复杂语义不敏感；VQAScore 虽更强，仍可能只验证表层文本匹配。知识型图像还会同时涉及事实正确、物理合理与视觉质量，因此 WISE 引入带明确 rubric 的三维评分，而不是单一 embedding 相似度。

02统计量与能力轴

1,000 条 prompt 均配有预期视觉线索和知识解释，目标实体尽可能不被直接点名。数据来自教材、百科、常识题与 LLM 候选，再由人工筛除不可视觉回答、过度冷门或事实不稳定的样本。

文化常识 · 400节日 · 体育 · 宗教 · 工艺 · 建筑 · 动植物 · 艺术 · 名人 · 日常生活
时空推理 · 300横向时间 · 纵向时间 · 地理位置 · 相对位置 · 不同视角
自然科学 · 300状态 / 行为 · 力学 / 热学 / 光学 · 物性 / 燃烧 / 腐蚀 / 溶液反应 / 化学性质

它评估的不是知识问答本身，而是知识检索、隐含语义理解、推理和视觉实现四步能否连通。

03指标、验证与重要信息

WiScore：VLM judge 分别对 Consistency、Realism、Aesthetic Quality 给 0 Rejected / 1 Conditional / 2 Exemplary；按 0.7 / 0.2 / 0.1 加权并除以 2，归一到 [0,1]。高权重放在 consistency，是为了让事实和知识约束成为主导信号。论文主实验使用固定版本 GPT-4o，并用 Gemini 与 Qwen judge 验证排名稳定性。

人类验证：在 Qwen-Image 与 UniWorld 上各采 180 张图，每张由 5 人独立评三维指标，可使用搜索引擎核实事实。Consistency / Realism / Aesthetics 的 Krippendorff’s α 为 0.82 / 0.78 / 0.67，WiScore 在论文对比中与人评最接近。

关键发现：多数模型总体 WiScore 低于 0.6，化学最难；原始 20 模型中 BAGEL + CoT 达 0.70，明显高于不带 CoT 的 0.52。把隐含 prompt 改写为直接答案后几乎所有模型显著提升，说明瓶颈既包括知识不足，也包括知识调用与理解-生成接口不畅。

使用提醒 世界知识会变化且存在文化覆盖偏差。论文已做全球 / 西方 / 非西方分布审计，仓库还发布了更新的 WISE_Verified；正式报告时应固定题集版本与 VLM judge 版本。

01为什么要做

人类美学偏好是最终目标，却不适合在预训练与对齐过程中频繁运行。团队需要一个快速、稳定、可按类别观察趋势的自动代理指标，判断每次训练迭代是否让生成分布更接近高质量图像。

为什么是新的 benchmark 而非新 metric

它沿用 FID，但把参考集变成经美学分数与 CLIPScore 筛选的 Midjourney 5.2 高质量生成图，并报告每类 FID。创新主要在参考分布与评测切片，而非 FID 公式。

02统计量与能力轴

30,000 张参考图，10 类各 3,000 张：animals、art、fashion、food、indoor、landscape、logo、people、plants、vehicles；图像与 prompt 在类内也强调多样性。

整体美学类别质量人像细节色彩 / 对比度多宽高比真实用户偏好

核心是 aesthetic quality，而不是逐 prompt 的语义忠实度；分类 FID 还能暴露 people、fashion、logo 等垂直领域差异。

03配套人评与重要信息

自动部分：在 1024×1024 上计算 overall 与 per-category FID，越低越好。论文报告 SDXL 1.0 + refiner / Playground v2 / Playground v2.5 的 overall FID 分别为 9.55 / 7.07 / 4.48。

人评部分：Internal-1K 来自产品真实用户 prompt；People-200 专测人像；另覆盖从 9:16 到 16:9 的 7 种比例。每对图至少由 7 名不同用户盲选，至少 2 票优势才判胜，单项研究涉及数千用户。

使用提醒 MJHQ-30K 的“好看”被 Midjourney 5.2 参考分布定义，存在审美风格偏置；FID 又是分布级指标，不能判断某一张图是否严格遵循了 prompt。

01为什么要做

旧 benchmark 常见四类问题：prompt 长度单一，无法测语义不变时的长度敏感性；模板语义重复；CLIP/BLIP/检测器对复杂场景过粗；把完整 caption 塞给 VLM 做整体打分会诱导 judge 根据文本先验“脑补”图中不存在的条件。

为什么需要多种专用指标

指令遵循不是一个同质任务：一般语义适合逐属性 yes/no，文字渲染需要 OCR 序列匹配，风格控制需要参考图特征相似度。用单一 holistic reward 会丢失可解释性，也可能奖励错误维度。

02统计量与能力轴

5,000 条 prompt 均有核心语义相同的 short / long 版本，对应 12,074 个二值问题；TestMini 为 554 prompts / 1,446 questions。数据由 10 个 concept pools 与 36 种组合策略构建，另含 100 条设计师级真实任务。

Basic: 属性 / 关系 / 推理Advanced: 跨组组合文字渲染风格控制Designer-level长短 prompt 鲁棒性

style reference 覆盖 16:9、5:4、1:1、4:5、9:16 五种比例，避免把宽高比变化误判为风格能力下降。

03指标、训练与重要信息

TIIF Evaluator：每个核心概念变成一个独立二值问题，图像得分为回答正确率。评测器从 Qwen3VL-8B 微调而来；训练语料覆盖 30 个 T2I 模型、两次 rollout、约 300K 图与 724K 问题，平衡后使用 109K 正例 + 109K 负例，并输出可解释推理。

GNED：对目标文字与 OCR 结果做 Hungarian 全局最优匹配，再按完整目标 / 预测集合归一化，同时惩罚漏字和多字。100 个文字样例上与人类偏好一致率 99%，高于 PNED 的 94% 与 OCR Recall 的 83%。风格则使用参考图的 CSD 与 DINOv3 相似度。

额外价值 它把 prompt 长度作为受控变量：强模型通常在 short / long 间稳定，弱模型差异显著。因此可以区分“会画某概念”与“能从冗长自然语言里稳定抓住概念”。

01为什么要做

前沿模型已在基础画质和粗粒度对齐上挤进相近分数区间，旧 benchmark 难以区分生产级系统。它们也很少评价物理、文化与事实正确性，或创作者真正关心的原创性、文字排版、镜头语言和设计落地能力。

为什么需要新的 judge

单一 MLLM 的无监督整体评分会把自身偏见当成标准，且强势信号会淹没细微缺陷。Q-Judger 用专业人员逐 facet、逐 rubric 的标签训练，把每个分数追溯到具体创作能力，而不是复刻一个通用模型的审美。

02统计量与能力轴

1,000 个 prompt 在 17 个应用域中构建，500 short + 500 long，每条都有中英文版本，平均同时激活 3–5 个一级支柱。18 个代表模型分别在中英文全集上评测。

03指标、监督与重要信息

Q-Judger：基于 Qwen3.6-27B 微调，对 56 个 L3 facets 分别给 0 Fail / 1 Pass / 2 Excel / N/A；再映射为 0 / 60 / 100，自底向上聚合到 L2、L1 与总分。N/A 不参与均值，因此单项缺陷不会被无关维度稀释。

专家监督：80 名具备摄影、导演或美术背景的艺术院校标注者盲标，每个 pair 至少三人独立交叉复核；训练集超过 130,000 个双语 prompt-image pairs。Q-Judger 与专家对 18 个模型的排序，在五大支柱上的 Spearman ρ 约为 0.89–0.92。

关键观察 Creative Generation 的模型间方差超过 Quality 的 11 倍；最能拉开差距的 facets 包括 Text Accuracy、Information Visualization 与 Cross-lingual Generation。基础画质已经接近“入场券”，专业执行力才是新前沿。
没有匹配项 换一个关键词或评测方向。
