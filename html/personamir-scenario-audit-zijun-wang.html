Scenario 人工审核说明

请在开始打分前完整阅读以下标准和示例。进入审核后，可以随时返回本页查看。

Scenario 的定义与第一性原则

Scenario 是以用户 [X] 为主体、发生在后续交流之前的一段真实生活情境；第一性原则是只保留让现实事件成立、让目标属性成为核心、并让稳定偏好（或明确的当前状态）自然显露的最小充分事实，同时为后续对话留下展开空间。

01

单条 Scenario 审核重点

逐条阅读正文，并结合绑定性、商品类型、属性和覆盖值进行判断。

  1. 真实、自然 应是现实中可能发生的生活事件，而不是画像、实验说明、值域模板或完整对话剧本；中文表达应自然。
  2. 目标属性居中 目标属性应直接影响事件中的动作、感受、判断或结果，不能只是顺带出现。
  3. 偏好依据成立 稳定偏好应从体验、习惯、现实取舍或熟人认知中自然显露，不能只靠“长期、一直、多次”等总结。Season 等近期状态类 Scenario 只需当前状态明确。
  4. 属性值能够自然代入 覆盖值代入 [Y] 后，语言、人物行为、物理结果和现实常识仍应成立。
  5. 信息充分但保持开放 应说明属性为什么重要，但不提前写完选择、处理及最终结果，给后续对话留下空间。
  6. 绑定关系合理 Product-bound 可以自然省略商品名，但商品类别必须能够从语境恢复；Non-product 不应依赖某个具体商品类别。

02

大类如何评价

大类评价关注整体是否存在系统性问题，不要求零丢弃。

满意

单条问题较为孤立；各属性组整体自然，值映射基本合理，生活事件和偏好证据具有多样性。

不满意

同一种问题反复出现，影响完整属性组或多个属性；例如属性因果普遍错误、值域被强行覆盖、语言模板化，或大量 Scenario 只是更换人物和地点。

少量单条 Scenario 被丢弃，不自动意味着整个大类不满意。选择“不满意”时，只需简要填写主要问题。

03

好的 Scenario 示例

以下示例分别展示自然省略、商品名显式出现、属性直接因果和真正 Non-product。

好例子 Product-bound · 商品名自然省略 · Tops / Color
[X]在试衣间面对一排候选，拿起[Y]那件套过头。领口和袖口落回熟悉的近脸色调后，[X]不再用围巾遮挡，同行人也把另外两件重新挂回原位。

试衣间、套过头、领口和袖口可以自然恢复上装类别；颜色直接影响行为，偏好也从熟悉动作中显露。

好例子 Product-bound · 商品名显式出现 · Bags / Material
第一只替代包在普通使用中失效，[X]回到换货柜台试一只[Y]材质的候选。店员说可以把平时随身带的东西装进去试试，[X]便照自己平时挑日用包的习惯，留意提手受力后稳不稳、肩带贴在身上会不会硌。

“替代包”和“日用包”自然说出商品类别；材质通过真实试装和身体感受参与判断，稳定依据来自既有挑选习惯。

好例子 Product-bound · 属性直接因果 · Glasses / Frame Pattern
[X]正在为夏日渡轮航程做准备，拿出平时常戴的[Y]纹样眼镜。想到船舱里的近距离交谈，[X]觉得这副镜框能保留自己的辨识度。

镜框纹样与近距离交流中的个人辨识度直接相关，“平时常戴”提供了简洁的稳定依据。

好例子 Non-product · Sport
[X]从家人那里学会在山地进行[Y]，熟悉路线边界、天气变化和如何不惊扰周围动物。最近旧路线被倒木截断，[X]没有冒险穿过，而是带同伴沿安全方向重新寻找通路。

运动项目本身决定行为和判断，不依赖具体商品；经验、熟练动作和现场选择共同体现持续投入。

04

不好的 Scenario 示例

信息看似丰富，但目标属性没有形成真实因果。

反例 Product-bound · Glasses / Frame Pattern
[X]正在为夏日渡轮航程做准备，拿出平时常戴的[Y]纹样眼镜。想到甲板强光、旅行照片和同行人的目光，[X]觉得还是自己一直喜欢的[Y]最好。

甲板强光实际关联镜片功能，而不是镜框纹样；旅行照片和旁人目光没有形成必要因果；“一直喜欢”只是作者总结，没有通过具体行为或判断体现偏好。
