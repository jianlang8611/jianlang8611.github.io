# AOEPT Project Page

Static project page for:

`AOEPT: Breaking the Implicit Modality-Reduction Bottleneck in Modality-Missing Prompt Tuning`

## Local preview

```bash
cd project-page
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

This page uses only relative asset paths, so it can be deployed directly under a personal homepage subpath such as:

`https://your-domain.com/aoept/`

Upload the full `project-page/` directory contents to the target folder:

- `index.html`
- `assets/`
- `.nojekyll`
